# 🚀 Job Tracker App

A modern React-based Job Tracker Application that helps users manage and track job applications efficiently.

## 📌 Features

- ➕ Add New Jobs
- ✏️ Edit Existing Jobs
- 🗑️ Delete Jobs
- 🔍 Search Jobs by Company Name
- 🎯 Filter Jobs by Status
- 📊 Dashboard Statistics
- 💾 Local Storage Support
- 📱 Responsive Design
- 🎨 Modern UI with CSS

---

## 📸 Application Features

### Dashboard
- Total Jobs Count
- Applied Jobs Count
- Interview Jobs Count
- Selected Jobs Count
- Rejected Jobs Count

### Job Management
- Add Job Applications
- Edit Company Names
- Delete Applications
- Track Application Status

### Search & Filter
- Search by Company Name
- Filter by:
  - Applied
  - Interview
  - Selected
  - Rejected

### Data Persistence
- Local Storage Integration
- Data remains available after browser refresh

## ⚙️ Installation

### Clone Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Navigate to Project

```bash
cd job-tracker-react
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
